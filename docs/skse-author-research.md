# SKSE Plugin Author Research

Checked 2026-09-17. Scope: enabled MO2 mods explicitly tagged `[SKSE]`.

Nexus kudos are a rough profile-level context signal, not a code review or a
measure of whether a plugin is safe. A low count is a prompt to inspect the
source, requirements, changelog, bug reports, and recent user feedback more
carefully. A high count does not guarantee quality or compatibility.

Counts below are approximate because profile kudos change over time. The
measured profile is the Nexus uploader when the page's creator and uploader
differ.
